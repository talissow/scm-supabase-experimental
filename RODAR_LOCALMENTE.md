## Rodando Localmente - Resumo Rápido

### 1️⃣ Instale Node.js
https://nodejs.org (v18+)

### 2️⃣ Clone o Projeto
```bash
git clone https://github.com/talissow/scm-supabase-experimental.git
cd scm-supabase-experimental
git checkout progresso-do-projeto
npm install
```

### 3️⃣ Configure Supabase
```bash
cp .env.local.example .env.local
# Edite .env.local com suas credenciais
```

### 4️⃣ Rode Localmente
```bash
npm run dev
# Acesse http://localhost:3000
```

### 5️⃣ Faça Login
- Email: admin@scm.local
- Senha: password

### 6️⃣ Teste Tudo
Abra `CHECKLIST_TESTES_LOCAL.md`
