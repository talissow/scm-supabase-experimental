# ☁️ GitHub Codespaces - Dev na Nuvem (Grátis!)

## O Melhor para Máquina Travada

GitHub oferece **120 horas GRÁTIS por mês** de VS Code na nuvem.

Você RODAS Node sem instalar NADA na sua máquina.

---

## 3 Passos

### 1️⃣ Abra GitHub
https://github.com/talissow/scm-supabase-experimental

### 2️⃣ Clique "Code"
- Selecione aba: **Codespaces**
- Clique: **Create codespace on progresso-do-projeto**

### 3️⃣ Espera 30-60 segundos
Um VS Code completo abre no seu browser!

---

## Agora Roda

No terminal que já está aberto:

```bash
npm install
npm run dev
```

Espera 30 segundos...

Terminal mostra:
```
▲ Next.js 14.0.0
- Local: http://localhost:3000
```

---

## Acesse

Clique no link `http://localhost:3000` (vai abrir automaticamente)

Pronto! Seu app está rodando NA NUVEM!
