# 📋 Opções de Teste - Escolha Uma!

## Seu Cenário
- Máquina do trabalho com restrições

- Quer testar antes de deploy

## Você tem 4 caminhos

### 1️⃣ AGORA - Preview v0 (Recomendado para Ver UI)
- Clique em "Preview" aqui no v0
- Vê toda a interface
- Testa navegação, dark mode, responsividade
- Zero setup

**Limitação:** Não faz chamadas reais ao Supabase

---

### 2️⃣ Rápido (5 min) - GitHub Codespaces (Recomendado para Dev)
- Cria um VS Code na nuvem
- Roda Node na nuvem (não precisa instalar)
- Todas as funcionalidades reais
- Grátis (GitHub oferece 120 horas/mês)

**Link:** https://github.com/talissow/scm-supabase-experimental

**Passos:**
1. Va no link acima
2. Code → Codespaces → Create codespace
3. Espera 1 minuto
4. Terminal abre
5. `npm install && npm run dev`
6. Pronto!

---

### 3️⃣ Internet (2 min) - Vercel Deploy (Recomendado para Usar)
- Deploy automático
- App vive na internet
- Compartilha link com outros
- Usa do celular/tablet de qualquer lugar

**Link:** https://vercel.com/new

**Passos:**
1. Clique "Import Project"
2. Cole: https://github.com/talissow/scm-supabase-experimental
3. Branch: progresso-do-projeto
4. Configure .env
5. Deploy (automático em 2 min)
6. Acesse via URL pública

---

### 4️⃣ Local (Se Tiver Docker)
- Docker Desktop rodando
- Não precisa Node instalado
- Roda em container
